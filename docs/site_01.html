3 Eglin Air Force Base (Florida)

We’re going to use this first study site and associated data to demonstrate the entire analysis process which includes:

  • Reference Field Data: load and attempt to standardize the field reference spatial tree inventory and polygon plot data
  • Point Cloud Data: process the raw point cloud data to generate the CHM used for individual tree detection
  • Individual Tree Detection: Use the CHM for individual tree detection. This includes many steps.
    • Utilize multiple window functions for ITD
    • Evaluate detection accuracy with segmentation matching of the predicted crowns with the field reference points
    • Select the best performing window function with the ITD result used for the remaining species method validation
  • Species/Genus Prediction: Predict species for the point cloud-generated tree list
  • Tree-level Species/Genus Evaluation: Evaluate the tree-level accuracy of the proposed classification method
  • Site-level Species/Genus Evaluation: Evaluate the site-level accuracy of the proposed classification method based on proportional distributions

3.0.1 Field Data

Field data from this study site is from:

  • Andrew Hudak, Seth Bigelow, Nuria Sánchez-López, and Vanessa Niemczyk. 2025. Field measurements of coarse wood, duff, litter, and trees for the Eglin Air Force Base 2023 fuels campaign. Wildland Fire Science Initiative (WFSI) https://doi.org/10.60594/W4RG6P

Field measurements collected before and after 2023 study fires at Eglin Air Force Base (AFB) to document fuel loads (large diameter fuels, litter depth, duff depth) and trees in a 3-year rough in sandhill longleaf pine, and the effects of study fires on these variables. Fuel loads, which were measured along transects, were co-located with tree observations, which were measured within fixed-radius plots. These field observations were also co-located with three-dimensional fuel and laser scan plots to allow for leveraging of these other data.

After the study fires in March 2023, trees within 10 m of plot center were identified to functional group (pine, hardwood or species), measured for diameter at breast height with a diameter tape, measured for distance from outer bark to plot center, and measured for azimuth from plot center to tree. Some post-processing was done using lidar scans to distinguish between evergreeen and deciduous hardwoods. Saplings were tallied by ordinal quadrant (up to 5 m from plot center). Tree measurements were not taken in unit L25. In unit G20, plots HH01, HH02, HH03, HH04, HH05 were sampled pre-fire but not post fire. In unit G25, plots HH105, HH95, PP16 were sampled pre-fire but not post fire.

according to Eglin_2022_Tree_and_Transect_Field_Protocol.pdf, the post-fire sampling protocol for trees was:

I. Determine if plot radius is 8 or 11.3 meters and record on datasheet a. If there are 4 or more trees within an 8-meter radius, then the plot radius is 8-meters. b. If there are 0 to 3 trees within an 8-meter radius, then increase the plot radius to 11.3-meters. II. Sample all trees ≥10 cm DBH within the plot radius and over from plot center III. Sample all pine saplings ONLY ≥2.5 to 10 cm DBH by recording: a. Radius (4 or 5.6m): i. If tree sampling radius was 8-meters, then sapling sampling radius = 4-meters ii. If tree sampling radius was 11.3-meters, then sapling sampling radius = 5.6-meters b. Quadrant = NE, SE, SW, or NW c. Count = How many of the same species in that quadrant d. Species = Longleaf pine (Pinus palustris), Loblolly pine (Pinus taeda), Sand pine (Pinus clausa) or TBD

3.0.2 Point Cloud Data

Andrew Hudak, & Benjamin Bright. (2026). Airborne Lidar Data from the 2023 Department of Defense Wildland Fire Science Initiative Eglin Air Force Base Campaign. WFSI Data Portal. doi:10.60594/W4B017

This dataset contains airborne light detection and ranging (lidar) data across burn units G20, G25, and L25 in Eglin AFB, FL. Kucera International acquired airborne lidar on January 28, 2023 (before prescribed fire), and on April 26, 2023 (after prescribed fire); prescribed fires occurred from March 11 to 19, 2023. Lidar data were acquired to characterize pre- and post-fire vegetation and estimate fire-caused biomass consumption.

some other relevant notes about the data:

Kucera International acquired airborne lidar data across burn units G20, G25, and L25 on January 28, 2023 (before prescribed fire), and across burn units G20 and G25 on April 26, 2023 (after prescribed fire); prescribed fires occurred from March 11 to 19, 2023. The lidar sensor, an Optech Galaxy T2000, was mounted on a PA-31 Piper Navajo Chieftain fixed-wing aircraft, which flew at an elevation of 1341 m (4400 ft) above ground level at a speed of about 150 knots, with a planned sidelap of 30%. The Optech Galaxy T2000 scanned with a laser pulse rate of 1600 kHz, a scan rate of 150 Hz, and a scan field of view of 30 degrees, which resulted in swath widths of 716 meters (2350 feet) and an average point density of 15 points per square meter.

LAZ file horizontal distance units are meters, in the UTM Zone 16N NAD83 (2011) geographic coordinate system (EPSG 6345)

get_ptcld_density_chm_res_fn <- function(las_ctg, rast_res_buffer = 0.01, min_chm_res_m = 0.15, chm_factor_for_dtm = 2) {
  rast_res_buffer <- dplyr::coalesce(as.numeric(rast_res_buffer),0)
  min_chm_res_m <- dplyr::coalesce(as.numeric(min_chm_res_m),0.15)
  chm_factor_for_dtm <- dplyr::coalesce(as.numeric(chm_factor_for_dtm),2)
  
  if(!inherits(las_ctg, "LAScatalog")){stop("must be a `LAScatalog` read with `lidR::readLAScatalog()`")}
  if(
    !( methods::slotNames(las_ctg) %>% stringr::str_equal("data") %>% any() )
  ){stop("can't find `data` layer in `LAScatalog` read with `lidR::readLAScatalog()`")}
  if(!inherits(las_ctg@data, "sf")){stop("non-sf `data` from `LAScatalog` read with `lidR::readLAScatalog()`")}
  
  # some point clouds have tiles with lots of overlap
  # some point clouds have tiles with no overlap
  
  # union over total area will help us identify overlap
  # high overlap >> union will be much smaller than total area (e.g., uoa ratio < 0.66)
  # low overlap >> union will be similar to total area (e.g., uoa ratio > 0.88)
  
  # union area
  las_uoa_temp <- 
  (
    las_ctg@data %>% 
    dplyr::ungroup() %>% 
    sf::st_union() %>% 
    sf::st_area() %>% 
    as.numeric()
  ) /
  # tot area
  (
    las_ctg@data %>% 
    dplyr::ungroup() %>% 
    dplyr::mutate(
      area_m2 = sf::st_area(geometry) %>% as.numeric()
    ) %>% 
    dplyr::summarise(area_m2=sum(area_m2,na.rm=T)) %>% 
    dplyr::pull(area_m2)
  )
  # las_uoa_temp
  # when a lot of overlap, union and calculate density based off union
  if(las_uoa_temp<0.66){
    pts_m2_temp <- 
      sum(las_ctg@data$Number.of.point.records,na.rm=T) /
      ( las_ctg@data$geometry %>% sf::st_union() %>% sf::st_area() %>% as.numeric() )  
  }else{
  # when NOT a lot of overlap, calculate density as-is
    pts_m2_temp <- 
      las_ctg@data %>% 
      dplyr::mutate(
        area_m2 = sf::st_area(geometry) %>% as.numeric()
      ) %>% 
      sf::st_drop_geometry() %>% 
      dplyr::ungroup() %>% 
      dplyr::summarise(
        pts_m2 = sum(Number.of.point.records,na.rm = T)/sum(area_m2,na.rm = T)
      ) %>% 
      dplyr::pull(pts_m2)
  }
  # pts_m2_temp
  # 1/sqrt(pts_m2_temp)
  
  chm_res_m_temp <- max(round(1/sqrt(pts_m2_temp),2) + rast_res_buffer, min_chm_res_m) 
  dtm_res_m_temp <- round(as.numeric(chm_res_m_temp)*chm_factor_for_dtm,2)
  
  return(list(
    pts_m2 = pts_m2_temp
    , chm_res_m = chm_res_m_temp
    , dtm_res_m = dtm_res_m_temp
  ))
}

3.0.3 Tree Detection

cloud2trees implements a CHM-based individual tree detection method accessible via cloud2trees::raster2trees(). this method requires a window function used to set the search radius used to find local maxima in the CHM. These local maxima represent individual tree top points and are subsequently used to delineate individual tree crowns via a marker-controlled watershed segmentation

because the objective of this study is to evaluate a species/genera classification method, we just want the best ITD results we can get based on the field reference data. We are not interested in evaluating tree segmentation here, that has already been done across varied input data and forest types.

let’s make a function to test many different window functions, compare the segmentation results to the field reference data, then select the best window function based on tree detection accuracy.

get_ws_fn_list <- function(min_ws = 0.5, max_ws = 6.0, n_linear = 40, n_concave = 30, n_cr = 30, max_ht = 45) {
  
  # empty list
  ws_functions <- list()
  
  ###########################################################################
  # linear functions over a range
  ###########################################################################
  # end points for the line
  linear_targets <- base::seq(from = max_ws, to = max_ws*4*10, length.out = n_linear)
  
  n_linear_pad <- ceiling(n_linear*1.5)
  
  for (i in 1:n_linear_pad) {
    target_height <- linear_targets[i]
    slope <- (max_ws - min_ws) / target_height
    
    # Pad names with a zero (01 to 60) for clean sorting
    func_name <- base::paste0("linear_", base::sprintf("%02d", i))
    
    v_min  <- base::as.numeric(min_ws)
    v_max  <- base::as.numeric(max_ws)
    v_slope <- base::as.numeric(slope)
    
    func_body <- base::substitute(
      dplyr::case_when(
        base::is.na(x) ~ v_min,
        (v_min + v_slope * x) < v_min ~ v_min,
        (v_min + v_slope * x) > v_max ~ v_max,
        TRUE ~ (v_min + v_slope * x)
      ),
      list(v_min = v_min, v_max = v_max, v_slope = v_slope)
    )
    
    ws_functions[[func_name]] <- base::as.function(c(base::alist(x = ), func_body))
  }
  
  # the flat slopes are too close together...let's remove every other one
  # how many to remove
  num_to_remove <- length(ws_functions) - n_linear
  
  # half
  start_idx <- length(ws_functions) - (num_to_remove - 1) * 2
  
  # remove
  remove_idx <- seq(from = start_idx, to = length(ws_functions), by = 2)
  ws_functions <- ws_functions[-remove_idx]
  names(ws_functions) <- base::paste0("linear_", base::sprintf("%02d", c(1:length(ws_functions)) ))

        base::is.na(x) ~ v_min,
        (v_min + ((v_max - v_min) * x) / (v_half + x)) < v_min ~ v_min,
        (v_min + ((v_max - v_min) * x) / (v_half + x)) > v_max ~ v_max,
        TRUE ~ (v_min + ((v_max - v_min) * x) / (v_half + x))
      ),
      list(v_min = v_min, v_max = v_max, v_half = v_half)
    )

  ###########################################################################
  # Generate parameters that smoothly spread across your MAX_CANOPY_HEIGHT
  # Beta controls horizontal stretching; Gamma controls the sharpness of the initial lag
  beta_sequence  <- base::seq(from = 0.15, to = 0.02, length.out = n_cr)
  gamma_sequence <- base::seq(from = 1.5,  to = 4.0,  length.out = n_cr)
  
  for (i in 1:n_cr) {
    b_param <- beta_sequence[i]
    g_param <- gamma_sequence[i]
    
    func_name <- base::paste0("chapman_richards_", base::sprintf("%02d", i))
    
    v_min   <- base::as.numeric(min_ws)
    v_max   <- base::as.numeric(max_ws)
    v_beta  <- base::as.numeric(b_param)
    v_gamma <- base::as.numeric(g_param)
    
    # Chapman-Richards equation with case_when boundaries
    func_body <- base::substitute(
      dplyr::case_when(
        base::is.na(x) ~ v_min,
        TRUE ~ {
          # Core Chapman-Richards Sigmoid Formula
          val <- v_min + (v_max - v_min) * (1 - base::exp(-v_beta * x))^v_gamma
          dplyr::case_when(val < v_min ~ v_min, val > v_max ~ v_max, TRUE ~ val)
        }
      ),
      list(v_min = v_min, v_max = v_max, v_beta = v_beta, v_gamma = v_gamma)
    )
    
    ws_functions[[func_name]] <- base::as.function(c(base::alist(x = ), func_body))
  }
  
  return(ws_functions)
}

now we need a function to perform instance matching of the predictions and reference data. to keep things simple, since all the reference field data includes point locations, we’ll perform matching based on a spatial intersection of these points with the predicted tree crowns. if multiple tree points fall within a single crown, we’ll select the tree that is closest in terms of size based on whatever field data is available (height or DBH). One predicted tree will only be matched with one field reference tree and vice-versa.

# instance matching function for points reference and polys predictions
# matches a single set of predictions with a single reference set
instance_match_fn <- function(
  pred_crowns
  , ref_points
){
  # check
  if(
    !any( stringr::str_equal(names(pred_crowns),"treeID") ) ||
    !any( stringr::str_equal(names(ref_points),"treeID") )
  ){
    stop("both reference and predicted data must have `treeID` column")
  }
  
  if(nrow(ref_points)==0){return(NULL)}
  if(nrow(pred_crowns)==0 && nrow(ref_points)>0){
    return(
      ref_points %>% 
        sf::st_drop_geometry() %>% 
        dplyr::mutate(
          ref_match_idx = dplyr::row_number()
          , pred_match_idx = as.numeric(NA)
        ) %>% 
        dplyr::select(dplyr::all_of(c(
          "ref_match_idx"
          , "pred_match_idx"
        ))) %>% 
        dplyr::mutate(
          match_grp = "omission"
          , match_grp = factor(
            match_grp
            , ordered = T
            , levels = c(
              "true positive"
              , "commission"
              , "omission"
            )
          ) %>% forcats::fct_rev()
        )
    )
  }
  
  # set up matching col based on what data is available
  if(
    any( stringr::str_equal(names(pred_crowns),"tree_height_m") ) &&
    any( stringr::str_equal(names(ref_points),"tree_height_m") )
  ){
    pred_crowns <- pred_crowns %>% dplyr::mutate(xxx_match_col = as.numeric(tree_height_m))
    ref_points <- ref_points %>% dplyr::mutate(xxx_match_col = as.numeric(tree_height_m))
  }else if(
    any( stringr::str_equal(names(pred_crowns),"dbh_cm") ) &&
    any( stringr::str_equal(names(ref_points),"dbh_cm") )
  ){
    pred_crowns <- pred_crowns %>% dplyr::mutate(xxx_match_col = as.numeric(dbh_cm))
    ref_points <- ref_points %>% dplyr::mutate(xxx_match_col = as.numeric(dbh_cm))
  }else{
    stop("both reference and predicted data must have `tree_height_m` or `dbh_cm` column")
  }
  # get rid of data without data
  pred_crowns <- pred_crowns %>% dplyr::filter(!is.na(xxx_match_col), xxx_match_col>0) %>% 
    # make an id
    dplyr::mutate(xxx_id = dplyr::row_number())
  ref_points <- ref_points %>% dplyr::filter(!is.na(xxx_match_col), xxx_match_col>0) %>% 
    # make it the same crs
    sf::st_transform(sf::st_crs(pred_crowns)) %>% 
    # make an id
    dplyr::mutate(xxx_id = dplyr::row_number())
  
  # intersection for tp's
  i_temp <-
    pred_crowns %>% 
    dplyr::rename_with(
      .fn = ~stringr::str_replace(.x, "^xxx_", "xxx_pred_")
      , .cols = tidyselect::starts_with("xxx_")
    ) %>% 
    sf::st_intersection(
      ref_points %>% 
        dplyr::select(xxx_id,xxx_match_col) %>% 
        dplyr::rename_with(
          .fn = ~stringr::str_replace(.x, "^xxx_", "xxx_ref_")
          , .cols = tidyselect::starts_with("xxx_")
        )
    ) %>% 
    sf::st_drop_geometry() %>% 
    # absolute diff between match col
    dplyr::mutate(
      xxx_abs_diff = abs(xxx_pred_match_col - xxx_ref_match_col)
    ) %>% 
    # sorting is key to make the purrr::reduce work how we want it
    dplyr::arrange(
      desc(xxx_pred_match_col)
      , xxx_pred_id
      , xxx_abs_diff
    )
  # i_temp %>% dplyr::glimpse()
  
  # if there even are any matches
  if(nrow(i_temp)>1){
    # ?purrr::reduce
    # purrr::reduce(letters[1:5], paste, sep = ".")
    # 1:3  %>% reduce(`+`)
    match_temp <- purrr::reduce(
      # go through all rows except first since we start there
      .x = c(2:nrow(i_temp))
      # start with the first row
      , .init = i_temp %>% dplyr::slice(1) # = iter_temp
      , .f = function(iter_temp, i){
        
        #ids of curr row
        pred_id  <- i_temp$xxx_pred_id[i]
        ref_id <- i_temp$xxx_ref_id[i]
        
        # either one used?
        pred_used  <- pred_id %in% iter_temp$xxx_pred_id
        ref_used <- ref_id %in% iter_temp$xxx_ref_id
        
        # add if freee
        if(!pred_used && !ref_used) {
          return(
            iter_temp %>% 
              dplyr::bind_rows(
                dplyr::slice(i_temp, i)
              )
          )
        }else{
          # return current state
          return(iter_temp)
        }
    })
    # match_temp %>% dplyr::glimpse()
    # match_temp %>% dplyr::count(xxx_pred_id) %>% dplyr::filter(n>1) %>% nrow()
    # match_temp %>% dplyr::count(xxx_ref_id) %>% dplyr::filter(n>1) %>% nrow()
  }else{
    match_temp <- i_temp
  }
  # match_temp %>% dplyr::glimpse()
  # these are matches
  return_df <- match_temp %>% 
    dplyr::rename(
      ref_match_idx = xxx_ref_id
      , pred_match_idx = xxx_pred_id
    ) %>% 
    dplyr::select(dplyr::all_of(c(
      "ref_match_idx"
      , "pred_match_idx"
    ))) %>% 
    dplyr::mutate(match_grp = "true positive")
  # return_df %>% dplyr::glimpse()

  return_df <-
    return_df %>% 
    # if reference but no predictions...they are all omissions (FN)
    dplyr::bind_rows(
      ref_points %>% 
        dplyr::filter(
          !(xxx_id %in% match_temp$xxx_ref_id)
        ) %>% 
        sf::st_drop_geometry() %>% 
        dplyr::rename(
          ref_match_idx = xxx_id
        ) %>% 
        dplyr::mutate(pred_match_idx = as.numeric(NA)) %>% 
        dplyr::select(dplyr::all_of(c(
          "ref_match_idx"
          , "pred_match_idx"
        ))) %>% 
        dplyr::mutate(match_grp = "omission")  
    ) %>% 
    # if predictions but no reference...they are all commissions (FP)
    dplyr::bind_rows(
      pred_crowns %>% 
        dplyr::filter(
          !(xxx_id %in% match_temp$xxx_pred_id)
        ) %>% 
        sf::st_drop_geometry() %>% 
        dplyr::rename(
          pred_match_idx = xxx_id
        ) %>% 
        dplyr::mutate(ref_match_idx = as.numeric(NA)) %>% 
        dplyr::select(dplyr::all_of(c(
          "ref_match_idx"
          , "pred_match_idx"
        ))) %>% 
        dplyr::mutate(match_grp = "commission")
    ) %>% 
    # add on treeID
    dplyr::left_join(
      ref_points %>% 
        sf::st_drop_geometry() %>%
        dplyr::select(xxx_id, treeID) %>% 
        dplyr::rename(
          ref_match_idx = xxx_id
          , ref_treeID = treeID
        )
      , by = "ref_match_idx"
    ) %>% 
    # add on treeID
    dplyr::left_join(
      pred_crowns %>% 
        sf::st_drop_geometry() %>% 
        dplyr::select(xxx_id, treeID) %>% 
        dplyr::rename(
          pred_match_idx = xxx_id
          , pred_treeID = treeID
        )
      , by = "pred_match_idx"
    )
    
  # return_df %>% dplyr::glimpse()
  # return_df %>% View()
  # return_df %>% dplyr::count(match_grp)
  
  # make match_grp factor
    return_df <- return_df %>% 
      dplyr::mutate(
        match_grp = factor(
          match_grp
          , ordered = T
          , levels = c(
            "true positive"
            , "commission"
            , "omission"
          )
        ) %>% forcats::fct_rev()
      )
    return(return_df)
}

ws_iter_instance_match_fn <- function(
  plot_sf # needs plot_id # should be a single plot

  if(

    if(

    ){
      pred_polys <- pred_polys %>% 
        dplyr::filter(
          dplyr::coalesce(fia_est_dbh_cm_upper,0) >= as.numeric(min_dbh_cm)
        )
    }else if(

        dplyr::filter(
          dplyr::coalesce(dbh_cm,0) >= as.numeric(min_dbh_cm)
        )
    }else{
      stop("`pred_polys` needs column named `dbh_cm`")
    }
    
    # do they exist? .... REF
    if(
      any( stringr::str_equal(names(ref_pts),"dbh_cm") )
    ){
      ref_pts <- ref_pts %>% 
        dplyr::filter(
          dplyr::coalesce(dbh_cm,0) >= as.numeric(min_dbh_cm)
        )
    }else{
      stop("`ref_pts` needs column named `dbh_cm`")
    }
  }else if(
    !is.na(as.numeric(min_ht_m))
  ){
    # do they exist? .... PRED
    if(
      any( stringr::str_equal(names(pred_polys),"tree_height_m") )

    ){
      ref_pts <- ref_pts %>% 
        dplyr::filter(
          dplyr::coalesce(tree_height_m,0) >= as.numeric(min_ht_m)
        )
    }else{
      stop("`ref_pts` needs column named `tree_height_m`")

  if(nrow(ref_pts)==0){return(NULL)}
  
  # map over it
  if(

      # remove commission points outside plot boundary?

    omission_rate = dplyr::case_when(
      dplyr::coalesce(tp_n,0) == 0 & dplyr::coalesce(fn_n,0) == 0 ~ 0 # if there are no actual trees, there is nothing to miss
      , dplyr::coalesce(tp_n,0) == 0 & dplyr::coalesce(fn_n,0) > 0 ~ 1 # every single actual tree was missed
      , dplyr::coalesce(fn_n,0) == 0 & dplyr::coalesce(tp_n,0) > 0 ~ 0
      , T ~ fn_n/(tp_n+fn_n)
    ) # False Negative Rate or Miss Rate
    , commission_rate = dplyr::case_when(
      dplyr::coalesce(tp_n,0) == 0 & dplyr::coalesce(fp_n,0) == 0 ~ 0 # if no predictions are made, the model could not have made any commission errors
      , dplyr::coalesce(fp_n,0) == 0 & dplyr::coalesce(tp_n,0) > 0 ~ 0
      , T ~ fp_n/(tp_n+fp_n)
    ) # False Positive Rate
    , precision = dplyr::case_when(
      dplyr::coalesce(tp_n,0) == 0 & dplyr::coalesce(fp_n,0) == 0 ~ 1 # if no predictions are made, the model made zero incorrect positive claims
      , dplyr::coalesce(tp_n,0) == 0 & dplyr::coalesce(fp_n,0) > 0 ~ 0
      , T ~ tp_n/(tp_n+fp_n)
    )
    , recall = dplyr::case_when(
      dplyr::coalesce(tp_n,0) == 0 & dplyr::coalesce(fn_n,0) == 0 ~ 1 # if there are no actual trees, there is nothing to miss
      , dplyr::coalesce(tp_n,0) == 0 & dplyr::coalesce(fn_n,0) > 0 ~ 0 # every single actual tree was missed
      , T ~ tp_n/(tp_n+fn_n)
    )
    , f_score = dplyr::case_when(
      dplyr::coalesce(precision,0) == 0 | dplyr::coalesce(recall,0) == 0 ~ 0
      , T ~ 2 * ( (precision*recall)/(precision+recall) )
    )    
  ) 
}

agg_ground_truth_match <- function(ground_truth_prediction_match_ans) {
  if(nrow(ground_truth_prediction_match_ans)==0){return(NULL)}
  if( !(names(ground_truth_prediction_match_ans) %>% stringr::str_equal("match_grp") %>% any()) ){stop("ground_truth_prediction_match_ans must contain `match_grp` column")}
  
  # check for difference columns (contains "_diff") and calc rmse for only those to return a single line df with colums for each diff_rmse
    if(
      (ground_truth_prediction_match_ans %>% 
        sf::st_drop_geometry() %>% 
        dplyr::select(tidyselect::starts_with("diff_") | tidyselect::starts_with("pct_diff_")) %>% 
        ncol() )>0
    ){
      # get rmse and mean difference/error for all columns with "_diff" but not "pct_diff"
      # get mape for all columns with "pct_diff" but not "diff_"
      rmse_df <- 
        ground_truth_prediction_match_ans %>% 
        sf::st_drop_geometry() %>% 
        dplyr::ungroup() %>% 
        dplyr::select(
          tidyselect::starts_with("diff_")
          | tidyselect::starts_with("pct_diff_")
        ) %>%
        tidyr::pivot_longer(dplyr::everything(), values_drop_na = T) %>% 
        dplyr::group_by(name) %>% 
        dplyr::summarise(
          sq = sum(value^2, na.rm = T)
          , mean = mean(value, na.rm = T)
          , sumabs = sum(abs(value), na.rm = T)
          , nomiss = sum(!is.na(value))
        ) %>% 
        dplyr::ungroup() %>% 
        dplyr::mutate(
          rmse = dplyr::case_when(
            dplyr::coalesce(nomiss,0)==0 ~ as.numeric(NA)
            , T ~ sqrt(sq/nomiss)
          )
          , mape = dplyr::case_when(
            dplyr::coalesce(nomiss,0)==0 ~ as.numeric(NA)
            , T ~ sumabs/nomiss
          )
        ) %>% 
        # NA nonsense values
        dplyr::mutate(
          mape = dplyr::case_when(
            stringr::str_starts(name, "pct_diff_") ~ mape
            , T ~ as.numeric(NA)
          )
          , rmse = dplyr::case_when(
            stringr::str_starts(name, "pct_diff_") ~ as.numeric(NA)
            , T ~ rmse
          )
          , mean = dplyr::case_when(
            stringr::str_starts(name, "pct_diff_") ~ as.numeric(NA)
            , T ~ mean
          )
        ) %>% 
        dplyr::select(name,rmse,mean,mape) %>% 
        tidyr::pivot_wider(
          names_from = name
          , values_from = c(rmse,mean,mape)
          , names_glue = "{name}_{.value}"
        ) %>% 
        # remove columns with NA in all rows
        dplyr::select( dplyr::where( ~!all(is.na(.x)) ) )
      
      if(
        dplyr::coalesce(nrow(rmse_df),0)==0
        || dplyr::coalesce(ncol(rmse_df),0)==0
      ){
        # empty df
        rmse_df <- dplyr::tibble()
      }
    }else{
      # empty df
      rmse_df <- dplyr::tibble()
    }
  
  # count by match group
    agg <-
      ground_truth_prediction_match_ans %>% 
      sf::st_drop_geometry() %>% 
      dplyr::ungroup() %>% 
      dplyr::count(match_grp) %>% 
      dplyr::mutate(
        match_grp = dplyr::recode_values(
          match_grp
          , "true positive"~"tp"
          , "commission"~"fp"
          , "omission"~"fn"
        )
      )
    # true positive, false positive, false negative rates
    return_df <- dplyr::tibble(match_grp = c("tp","fp","fn")) %>% 
      dplyr::left_join(agg, by = "match_grp") %>% 
      dplyr::mutate(dplyr::across(.cols = c(n), .fn = ~dplyr::coalesce(.x,0))) %>% 
      tidyr::pivot_wider(
        names_from = match_grp
        , values_from = c(n)
        , names_glue = "{match_grp}_{.value}"
      )
    # rates, precision, recall, f-score
    return_df <- confusion_matrix_scores_fn(return_df)
    # add rmse
    if(nrow(rmse_df)>0){
      return_df <- return_df %>% dplyr::bind_cols(rmse_df)
    }
  # return
  return(return_df)
}

get_relative_height_fn <- function(df, radius) {
    # Use the X and Y coordinates of the reference to build the tree.
    coords_temp <- 
      df %>% 
      sf::st_drop_geometry() %>% 
      sf::st_as_sf(coords = c("tree_x", "tree_y"), crs = sf::st_crs(df), remove = F) %>% 
      dplyr::mutate(
        X = sf::st_coordinates(.)[,1] %>% as.numeric()
        , Y = sf::st_coordinates(.)[,2] %>% as.numeric()
      ) %>% 
      dplyr::select(X,Y) %>% 
      sf::st_drop_geometry()
    # coords_temp %>% dplyr::glimpse()
    
    # perform a fixed-radius search using RANN::nn2
    # ?RANN::nn2
    nn_ans_temp <- RANN::nn2(
      # the point cloud xy data (builds the kd-tree on this)
      data = coords_temp
      # the seed point xy data (number of columns must be the same as data)
      , query = coords_temp
      # maximum number of neighbors to find per query
      , k = nrow(coords_temp)
      # the search radius (rcyl)
      , radius = radius
      , searchtype = "radius"
    )
    # nn_ans_temp %>% dplyr::glimpse()
    # nn_ans_temp$nn.idx[1:19,2:22]
    
    # iterate through the results to compute metrics
    w_ht <- 
      1:nrow(df) %>% 
      purrr::map(
        function(i) {
          # which seed?
          which_seed <- df %>% dplyr::slice(i)
          
          # get indices of points in the current radius (0 means no point found)
          # rad_pts <- nn_ans_temp$nn.idx[i, 2:ncol(nn_ans_temp$nn.idx)] # filter out self-idx in col 1
          rad_pts <- nn_ans_temp$nn.idx[i, ] # DON'T filter out self-idx in col 1
          rad_pts <- rad_pts[rad_pts > 0] 
          
          # if no other points, it's the tallest
          if (dplyr::coalesce(length(rad_pts),0) < 2) {
            return(
              which_seed %>% dplyr::mutate(rel_tree_height_m = 1)
            )
          }
          
          # get ht values using the indices
          ht_values <- df$tree_height_m[rad_pts]
          
          # relative ht
          my_rel_ht <- which_seed$tree_height_m / max(ht_values,na.rm=T)
          return(
            which_seed %>% dplyr::mutate(rel_tree_height_m = my_rel_ht)
          )
        }
      ) %>% 
      dplyr::bind_rows()
    
    return(w_ht)
}

3.0.4 Species/Genus Prediction Method

for some context of the primary objective of this analysis, here is what we said in the cloud2trees manuscript (a draft of the manuscript which may be different than what was actually published):

However, taxonomic differentiation using airborne lidar alone remains one of the most technically challenging aspects of forest inventory workflows (White et al., 2016, 2025; Fassnacht et al., 2024). In practice, genus-level distinction is often more realistic when relying on remote sensing and supplemental spatial data (Vauhkonen et al., 2014b). As a practical, computationally efficient approach, future research could evaluate predicting tree-level species or genus for potential integration into cloud2trees by leveraging supplemental spatial datasets. Testing could evaluate either using tree lists from FIA plots linked through a spatial overlay with TreeMap (Houtman et al., 2025) to train a taxonomic classification model based on structural and competition metrics shared between FIA and cloud2trees tree lists, or by proportionally assigning species using BigMap species-level proportional biomass raster data (Wilson et al., 2012, 2018). Incorporating finer-scale taxonomic classification than the currently implemented FIA forest type groups into the cloud2trees tree list will enable the integration of detailed biomass equations such as the National Scale Volume Biomass system (NSVB; Westfall et al., 2024) and other allometries that require species- or genera-level information (e.g., Réjou‐Méchain et al., 2017; Gonzalez‐Akre et al., 2022).

cloud2trees does not currently include functionality to attach species to it’s tree list. there are a few paths forward for performing species-specific workflows with the cloud2trees tree list:

the proposed method which we are evaluating presently, will predict tree-level species using the TreeMap imputed FIA plot tree list to build a species classification model based on height and tree location to attach tree species to our tree list. The model will inherently account for the proportional distribution of different species.

early testing of the proposed method used a bayesian hierarchical model grouped by imputed FIA plot identifier that allows the intercept and the slope of height to vary by plot took quite a while to run for a relatively small area (~20-30 mins). as such, we are going to use a random forest (RF) classifier to enable more computationally efficient classification. cloud2trees already implements random forest models to model missing HMD and CBH values that were not successfully extracted from the point cloud and uses a model averaging method that subsamples the training data (to reduce model fit times), estimates the model several times with different subsamples, then model averages the predictions. Because the species is not a metric variable that can be averaged, we’ll use the same method but employ a model majority voting system instead. we can do this with some of the cloud2trees built-in functionality.

ultimately, if the proposed species/genera classification method achieves decent accuracy results, it could be integrated into the cloud2trees framework as cloud2trees::trees_species(), for example. this function would take an input spatial tree list and attach the predicted species/genera

# custom window fn to get prop of surrounding cells matching focal value
# ?terra::focal
match_focal_cells_fn <- function(v, ...) {
  if(all(is.na(v))){ return(NA) }
  
  # center index of the window vector
  center_idx <- (length(v) + 1) / 2
  focal_val  <- v[center_idx]
  
  if(is.na(focal_val)){ return(NA) }
  
  # count how many cells in the window match the focal cell
  n_matches <- sum(v %in% focal_val, ...)
  prop_matches <- n_matches / length(v)
  
  return(prop_matches)
}

3.0.5 Predict Species/Genus Application

let’s implement a random forest model majority voting for species with the objective to reduce estimation time (compared to a Bayesian Softmax model)

tree species will be our dependent variable and the most simple model will use tree height and tree location (X and Y coordinates) as independent variables. The training FIA tree list data (identified from the TreeMap imputed plots of the area of interest) includes tree height and we’ll use the centroid of the TreeMap 30m raster cell to represent the individual tree X and Y location (i.e. each tree within the same cell will have the same coordinate). Considering the combined tree height and spatial location via a full interaction model (i.e. height*x*y) allows the model to capture how the species-height relationship varies across space.

rf_tune_subsample <- function(
  predictors
  , response
  , threshold = 14444
  , n_subsamples = 4
  , ntree_try = 44
  , step_factor = 1
  , improve = 0.03
) {
  # set upper limit for ntreeTry
  max_ntreeTry <- 122
  # count the obs
  n_obs <- nrow(predictors)
  # set up list to store values from subsample runs
  optimal_mtry_values <- numeric(as.numeric(n_subsamples))
  # quiet the thing
  quiet_tuneRF <- purrr::quietly(randomForest::tuneRF)
  # if we don't need to subsample
  if(
    n_obs<=threshold
  ){
    # get rid of missing factor levels if not in there
    # results in error: "Can't have empty classes in y." from randomForest::tuneRF
    if(inherits(response,"factor")){
      response <- forcats::fct_drop(response)  
    }
    
    # Tune on the full data if below threshold
    tune_result <- quiet_tuneRF(
      # randomForest::tuneRF(
      y = response
      , x = predictors
      , ntreeTry = max_ntreeTry # this is high for data with less obs
      , stepFactor = step_factor
      , improve = improve
      , plot = F
      , trace = F
    )
    # just get the result
    tune_result <- tune_result$result
    # Extract the optimal mtry value
    optimal_mtry <- tune_result %>%
      dplyr::as_tibble() %>%
      dplyr::filter(OOBError==min(OOBError)) %>%
      dplyr::filter(dplyr::row_number() == 1) %>%
      dplyr::pull(mtry) %>%
      as.numeric()
  }else{
    # number for subsample
    sample_obs <- as.numeric(threshold)
    # run tuning on subsamples
    for (i in 1:n_subsamples) {
      # subsample
      subsample_indices <- sample(x = 1:n_obs, size = sample_obs, replace = F)
      subsample_predictors <- predictors[subsample_indices, ]
      subsample_response <- response[subsample_indices]
      
      # get rid of missing factor levels if not in there
      # results in error: "Can't have empty classes in y." from randomForest::tuneRF
      if(inherits(subsample_response,"factor")){
        subsample_response <- forcats::fct_drop(subsample_response)  
      }
      
      # tune on subsample
      tune_result <- quiet_tuneRF(
        # randomForest::tuneRF(
        y = subsample_response
        , x = subsample_predictors
        , ntreeTry = min(as.numeric(ntree_try),max_ntreeTry)
        , stepFactor = step_factor
        , improve = improve
        , plot = F
        , trace = F
      )
      # just get the result
      tune_result <- tune_result$result
      # Extract the optimal mtry value
      optimal_mtry_values[i] <- tune_result %>%
        dplyr::as_tibble() %>%
        dplyr::filter(OOBError==min(OOBError)) %>%
        dplyr::filter(dplyr::row_number() == 1) %>%
        dplyr::pull(mtry) %>%
        as.numeric()
    }
    # Find most frequent optimal mtry
    optimal_mtry <- table(optimal_mtry_values) %>%
      sort(decreasing = TRUE) %>%
      .[1] %>%
      names() %>%
      as.numeric()
  }
  # ensure that the mtry value is not greater than the number of predictors
  optimal_mtry <- min(optimal_mtry, ncol(predictors))
  # return
  return(optimal_mtry)
}

################################################################################################################################################
# function to combine tuning and modelling
################################################################################################################################################
rf_tune_model <- function(
  predictors
  , response
  , tune_threshold = 14444
  , tune_n_subsamples = 4
  , tune_ntree_try = 44
  , tune_step_factor = 1
  , tune_improve = 0.03
  , ntree = 500
  , weights = NULL
) {
  ### tuning RF model
  # implements steps to mitigate very long run-times when tuning random forests models
  optimal_mtry <- rf_tune_subsample(
    predictors = predictors
    , response = response
    , threshold = tune_threshold
    , n_subsamples = tune_n_subsamples
    , ntree_try = tune_ntree_try
    , step_factor = tune_step_factor
    , improve = tune_improve
  )

  ### Run a randomForest model
  
  # get rid of missing factor levels if not in there
    # results in error: "Can't have empty classes in y." from randomForest::tuneRF
    if(inherits(response,"factor")){
      response <- forcats::fct_drop(response)  
    }
  
  # quiet this
  quiet_rf <- purrr::quietly(randomForest::randomForest)
  # run it
  mod <- quiet_rf(
    y = response
    , x = predictors
    , mtry = optimal_mtry
    , na.action = na.omit
    , ntree = ntree
    # # weights = A vector of length same as y that are positive weights (i.e. >0 for all obs)
    #   # used only in sampling data to grow each tree (not used in any other calculation)
    , weights = weights
  )

  # just get the result
  mod <- mod$result
  return(mod)
}
################################################################################################################################################
# function to subsample, tune, and model
################################################################################################################################################
rf_subsample_and_model <- function(
  predictors
  , response
  , tune_threshold = 14444
  , tune_n_subsamples = 4
  , tune_ntree_try = 44
  , tune_step_factor = 1
  , tune_improve = 0.03
  , mod_n_subsample = 20000
  , ntree = 500
  , weights = NULL
) {
  if(length(response)<=mod_n_subsample){
    mod <- rf_tune_model(
        predictors = predictors
        , response = response
        , tune_threshold = tune_threshold
        , tune_n_subsamples = tune_n_subsamples
        , tune_ntree_try = tune_ntree_try
        , tune_step_factor = tune_step_factor
        , tune_improve = tune_improve
        , ntree = ntree
        , weights = weights
      )
  }else{
    subsample_indices <- sample(x = 1:length(response), size = mod_n_subsample, replace = F)
    subsample_y <- response[subsample_indices]
    subsample_x <- predictors[subsample_indices,]
    # weights
    if(!is.null(weights) && !any(is.na(weights))){
      subsample_w <- weights[subsample_indices]
    }else{
      subsample_w <- NULL
    }
    
    mod <- rf_tune_model(
        predictors = subsample_x
        , response = subsample_y
        , tune_threshold = tune_threshold
        , tune_n_subsamples = tune_n_subsamples
        , tune_ntree_try = tune_ntree_try
        , tune_step_factor = tune_step_factor
        , tune_improve = tune_improve
        , ntree = ntree
        , weights = subsample_w
      )
  }
  return(mod)
}

# function to subsample, tune, and model N TIMES
# iterates the subsampling and model fitting process n_iterations times
# stores the predictions from each model in a list
################################################################################################################################################
rf_subsample_and_model_n_times <- function(
  predictors
  , response
  , tune_threshold = 14444
  , tune_n_subsamples = 4
  , tune_ntree_try = 44
  , tune_step_factor = 1
  , tune_improve = 0.03
  , mod_n_subsample = 20000
  , mod_n_times = 3
  , ntree = 500
  , weights = NULL
) {
  # set up blank list
  mod_list <- list()
  if(length(response)<=mod_n_subsample){
    mod_list[[1]] <- rf_subsample_and_model(
        predictors = predictors
        , response = response
        , tune_threshold = tune_threshold
        , tune_n_subsamples = tune_n_subsamples
        , tune_ntree_try = tune_ntree_try
        , tune_step_factor = tune_step_factor
        , tune_improve = tune_improve
        , mod_n_subsample = mod_n_subsample
        , ntree = ntree
        , weights = weights
      )
  }else{
    for (i in 1:mod_n_times) {
      mod_list[[i]] <- rf_subsample_and_model(
          predictors = predictors
          , response = response
          , tune_threshold = tune_threshold
          , tune_n_subsamples = tune_n_subsamples
          , tune_ntree_try = tune_ntree_try
          , tune_step_factor = tune_step_factor
          , tune_improve = tune_improve
          , mod_n_subsample = mod_n_subsample
          , ntree = ntree
          , weights = weights
        )
    }
  }
  return(mod_list)
}

rf_model_avg_predictions <- function(mod_list, predict_df, levels = NULL){
  mod_type_temp <- mod_list[[1]]$type
  if(mod_type_temp == "classification") {
    if(is.null(levels)){stop("this is a RF classifier and you need to provide `levels` based on training data")}
    predicted_temp <- rf_model_vote_predictions(
        mod_list = mod_list
        , predict_df = predict_df
        , levels = levels
      )
  }else{
    # if (mod_type_temp == "regression") {
    # get model predictions for each model
    predicted_temp <-
      1:length(mod_list) %>%
        purrr::map(function(x){
          predict(
            mod_list[[x]]
            , predict_df
          ) %>%
          dplyr::as_tibble() %>%
          dplyr::pull(1) %>%
          dplyr::as_tibble() %>%
          dplyr::rename(value=1) %>%
          dplyr::mutate(id=dplyr::row_number())
        }) %>%
        dplyr::bind_rows()
    # model average
    predicted_temp <- predicted_temp %>%
      dplyr::group_by(id) %>%
      dplyr::summarise(
        predicted = mean(value, na.rm = T)
      ) %>%
      dplyr::ungroup() %>%
      dplyr::arrange(id) %>%
      dplyr::select(predicted)
  }
  
  # return
  return(predicted_temp)
}

    dplyr::group_by(id) %>%

3.0.6.1 Tree-Level Accuracy

Given that our analysis is focused on evaluating the proposed taxonomic classification algorithm (rather than the individual tree detection method), we’ll evaluate the taxonomic classification accuracy conditionally for successfully detected tree crowns (true positive matches). This conditional evaluation will allow us to isolate taxonomic model performance from tree detection errors (reviewed above here). In practice, the ITD window function would be tuned for the specific site and data being analyzed, but we implemented an automated ITD window selection process here since we will be evaluating many different sites and forest types.

we’re going to use the tree-level prediction and reference data for all TP (true positive) predictions to perform confusion matrix accuracy evaluation of the species predictions.

using the confusion matrix evaluation we’ll calculate the following metrics:

  • Overall Accuracy: Measures the global percentage of all correctly classified trees out of the entire dataset of true positive (TP) observations. Provides an overall summary metric but can mask performance on uncommon species.
  • User’s Accuracy (precision): Measures the reliability of specific predicted species. For example, if the method predicts a tree is a ponderosa pine, how often it is actually true.
  • Producer’s Accuracy (recall): Measures how well the model successfully aligns with what was measured on the ground. For example, out of all real ponderosa pine trees measured in the field, what percentage did the method correctly identify.

\[\text{Overall Accuracy} = \frac{\text{Number of Correctly Classified Species Observations}}{\text{Total Number of Successfully Detected Trees (TPs)}}\]

\[\text{User's Accuracy (Species } i\text{)} = \frac{\text{Number of Correctly Classified Observations for Species } i}{\text{Total Number of Predicted Observations for Species } i}\]

\[\text{Producer's Accuracy (Species } i\text{)} = \frac{\text{Number of Correctly Classified Observations for Species } i}{\text{Total Number of Reference Observations for Species } i}\]

3.0.6.2 Site-Level Accuracy

we shift away from individual item matching and use the Bray-Curtis Dissimilarity Index. This metric compares the proportional compositions of each species predicted by the model against the reference proportions within a defined area or site.

Instead of evaluating trees one by one, this accuracy evaluation aggregates the species counts or proportions across an entire plot or forest stand. The Bray-Curtis dissimilarity index is used to compare the predicted species composition against the observed field composition. The index returns a value between 0 and 1, where 0 indicates identical species compositions and 1 indicates completely non-overlapping communities. Because Bray-Curtis is a dissimilarity measure, it can be interpreted as:

\[\textrm{Bray-Curtis}_{dissimilarity} \approx 1-\textrm{Bray-Curtis}_{similarity}\]

The Bray-Curtis index is a widely trusted metric in community ecology. Dissimilarity/similarity metrics tell us how well the proposed method captures the overall ecological community structure. Even if individual tree predictions are misaligned, the proposed method may still capture the correct stand-level abundance proportions, which can still be valuable for management.

What it means for this evaluation: Even if individual-level classification accuracy is low, the model may still achieve acceptable aggregate composition accuracy. Real-World Ecological Application: This aggregate evaluation is valuable for large-scale forest structure measurement including: timber management, carbon and fuel assessments, and landscape ecology patterns. If a forestry manager only needs to know the total volume, fuel loading, or biomass ratios of species across a broad area or management unit to write a management plan, they don’t care if individual tree predictions are slightly off. They care about aggregate community structure which makes Bray-Curtis (and other similiarity/dissimilarity metrics) more relevant than overall, producer’s, and user’s accuracy.

          .cols = -c(species_symbol)
          , .fn = ~paste0("species_",.x,recycle0 = T)
        )
        , by = "species_symbol"
      ) %>% 
      # clean up missing
      dplyr::mutate(
        dplyr::across(
          tidyselect::starts_with("species_") & !c("species_symbol")
          , .fns = ~dplyr::case_when(
            is.na(species_symbol) ~ "NONE"
            , is.na(.x) ~ "UNKNOWN"
            , T ~ .x
          )
        )
        , species_symbol = dplyr::case_when(
          is.na(species_symbol) ~ "NONE"
          , is.na(species_symbol) ~ "UNKNOWN"
          , T ~ species_symbol
        )
    ) %>% 
    # count reference trees
    dplyr::left_join(
      ref_trees %>% 
        sf::st_drop_geometry() %>%
        dplyr::ungroup() %>% 
        dplyr::count(species_symbol) %>% 
        dplyr::mutate(pct=n/sum(n)) %>% 
        dplyr::rename(
          ref_n=n
          , ref_pct=pct
        )
      , by = "species_symbol"
    ) %>% 
    # count pred trees
    dplyr::left_join(
      pred_trees %>% 
        sf::st_drop_geometry() %>%
        dplyr::ungroup() %>% 
        dplyr::count(species_symbol) %>% 
        dplyr::mutate(pct=n/sum(n)) %>% 
        dplyr::rename(
          pred_n=n
          , pred_pct=pct
        )
      , by = "species_symbol"
    ) %>% 
    dplyr::mutate(
      dplyr::across(
        dplyr::where(is.numeric)
        , ~ dplyr::coalesce(.x,0)
      )
    )
  # species_comp_temp
  
  if(use_genus){
    species_comp_temp <- 
      species_comp_temp %>% 
      dplyr::group_by(species_genus) %>% 
      dplyr::summarise(
        dplyr::across(
          dplyr::where(is.numeric)
          , ~ sum(.x,na.rm=T)
        ) 
      ) %>% 
      dplyr::ungroup()
  }
  # species_comp_temp
  
  # calc intersecting shared area per species (Schoener's Overlap index component)
  species_comp_temp <- 
    species_comp_temp %>% 
    dplyr::mutate(
      # for similarity index : Schoener's D (total overlap) Index
      overlap_pct = pmin(pred_pct, ref_pct)
      # for rmse : sqrt(mean(species_comp_temp$sq_pct_error))
      , sq_pct_error = (pred_pct - ref_pct)^2
    )
  
  # species_comp_temp
  
  if(use_genus){
    kbl_df_temp <- species_comp_temp %>% dplyr::rename(species_symbol=species_genus)
    cap_temp <- "Taxonomic Genus Proportional Comparision"
    head_temp <- "Genus Proportions and Tree Counts"
  }else{
    kbl_df_temp <- species_comp_temp
    cap_temp <- "Taxonomic Species Proportional Comparision"
    head_temp <- "Species Proportions and Tree Counts"
  }
  # table the predicted versus reference counts by species
  kbl_html_table_temp <-
    kbl_df_temp %>% 
    dplyr::mutate(diff_pct = pred_pct-ref_pct) %>% 
    dplyr::mutate(
      # # one column for diff/pct
      diff_pct = scales::percent(diff_pct,accuracy=0.1)
      , pred_pct = paste0(scales::percent(pred_pct,accuracy=0.1), "<br />(", scales::comma(pred_n,accuracy=1), ")")
      , ref_pct = paste0(scales::percent(ref_pct,accuracy=0.1), "<br />(", scales::comma(ref_n,accuracy=1), ")")
    ) %>% 
    dplyr::select(species_symbol, pred_pct, ref_pct, diff_pct) %>% 
    tidyr::pivot_longer(
      cols = c(pred_pct, ref_pct, diff_pct)
      , names_to = "dta"
      , values_to = "prop"
    ) %>% 
    dplyr::mutate(
      dta = dplyr::recode_values(
        dta
        , "pred_pct" ~ "predicted"
        , "ref_pct" ~ "reference"
        , "diff_pct" ~ "difference<br />(predicted-reference)"
      )
    ) %>% 
    tidyr::pivot_wider(
      names_from = species_symbol
      , values_from = prop
    ) %>% 
    dplyr::arrange(ifelse(stringr::str_starts(dta,"difference"),1,0), desc(dta)) %>% 
    dplyr::rename(`data`=dta) %>% 
    kableExtra::kbl(
      caption = paste0(
        cap_temp # "Taxonomic Proportional Comparision"
        # , "<br />Total Overlap Index: "
        # , sum(species_comp_temp$overlap_pct) %>% scales::percent(accuracy = 0.1 )
        # , "<br />Proportion RMSE: "
        # , sqrt(mean(species_comp_temp$sq_pct_error)) %>% scales::percent(accuracy = 0.1 )
      )
      , escape = F
    ) %>% 
    kableExtra::kable_styling(font_size = 11.5, bootstrap_options = c("responsive", "condensed")) %>% # 
    kableExtra::add_header_above(
      # named numeric vector req'd for dynamic label
      setNames( c(1,nrow(species_comp_temp)), c(" ", head_temp) )
    ) %>% 
    kableExtra::row_spec(
      c(2,3)
      # , border = T, 
      , extra_css = "border-bottom: 3px solid black !important;"
    )
  
  ## dissimilarity index
  # library(vegan)
  
  # format data and pass to vegan::vegdist for bray-curtis dissimilarity
  # ?vegan::vegdist
  # vegan needs a matrix :\
  bc_dissim_temp <-
    kbl_df_temp %>% 
    # relative props
    dplyr::select(species_symbol, pred_pct, ref_pct) %>% 
    tidyr::pivot_longer(cols = c(pred_pct, ref_pct), names_to = "which_dta", values_to = "n") %>% 
    tidyr::pivot_wider(names_from = species_symbol, values_from = n) %>% 
    dplyr::mutate(which_dta = ifelse(which_dta == "pred_pct", "predicted", "reference")) %>% 
    tibble::column_to_rownames(var = "which_dta") %>% 
    # rowSums() # should sum to 1 because proportions
    # # vegan::decostand(method = "total") %>% # if using counts, transform to propotions
    # dissimilarity
    vegan::vegdist(method = "bray") %>% 
    as.numeric()
  # sim
  bc_sim_temp <- 1 - bc_dissim_temp
  # table
  sim_table_temp <- 
    dplyr::tibble(
      metric = c(
        "Bray-Curtis Dissimilarity Index"
        , "Bray-Curtis Similarity"
        # , "Schoener's D (total overlap) Index"
        , "Proportional RMSE"
      )
      , value = c(
        bc_dissim_temp
        , bc_sim_temp
        # , sum(species_comp_temp$overlap_pct) 
        , sqrt(mean(species_comp_temp$sq_pct_error,na.rm=T))
      )
      , metric_desc = c(
        paste0("proportion of relative ", ifelse(use_genus,"genus","species")," distribution mis-matched")
        , "proportion of total distribution matching perfectly"
        # , "equal to Bray-Curtis similarity for proportions"
        , paste0("average percentage deviation error margin per ", ifelse(use_genus,"genus","species"))
      )
    )
  kbl_html_sim_table_temp <- 
    sim_table_temp %>% 
    dplyr::mutate(dplyr::across(
      dplyr::where(is.numeric)
      , ~scales::percent(.x,accuracy=0.1)
    )) %>% 
    kableExtra::kbl(
      caption = "Predicted vs Reference Compositional Accuracy Metrics"
      , col.names = c("","value","interpretation")
    ) %>% 
    kableExtra::kable_styling(font_size = 12, bootstrap_options = c("responsive", "condensed")) %>% # 
    kableExtra::column_spec(1:2, bold = TRUE)
  
  return(list(
    species_comp_df = species_comp_temp
    , kbl_html_comp_table = kbl_html_table_temp
    , sim_table_df = sim_table_temp
    , kbl_html_sim_table = kbl_html_sim_table_temp
  ))
}
